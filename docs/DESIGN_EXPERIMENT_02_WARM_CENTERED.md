# 디자인 깎기 EXP-02 — Warm-centered

> **브랜치:** `experiment/design-kkakgi-v1.2-warm-centered`
> **기준:** `main` / v0.1.4 / `38a02b96657363a8230c85115f9721b97bf902be`
> **상태:** 사용자 피드백 반영 실험 / 미승인 / main 및 정식 Pages 유지

## 피드백 → 설계

1. **차가운 배경이 오렌지 슬롯과 부조화**: 1차 실험의 청백색 배경은 폐기. 기존 아이보리와 따뜻한 샌드 스테이지를 복원한다.
2. **화면을 불필요하게 좌측으로 사용하는 경향**: 이 앱은 소규모 단일 작업이므로 최대 폭을 1000px로 제한하고 화면 중앙에 배치한다. 모드 선택과 메인 제목도 중앙 정렬한다.
3. **슬롯과 조작 패널의 크기 비율 및 정렬은 좋음**: 1차 실험에서 호평받은 1.3 : .82의 비율을 보존한다. 패널 내부 라벨은 좌측 정렬로 유지한다.
4. **물성은 상황에 적합하게 적용**: 슬롯의 약한 광택과 음영은 사용하되 식품 서비스에 맞지 않는 냉색 배경과 지나친 장식은 사용하지 않는다.
5. **작은 글씨**: 조작에 필요한 설명·상태는 대체로 12~14px 이상으로 개선한다. 매우 긴 메뉴명과 극소 화면은 렌더링 검증 대상이다.

## 변경 내용

- `main`에서 신규 브랜치를 생성했으며 실험01 코드는 따로 보존한다.
- 기존 `assets/css/styles.css` 및 전체 JS 모듈을 수정하지 않고 `assets/css/design-warm-centered.css`만 추가한다.
- `index.html`에는 비교를 위한 CSS 한 줄을 추가한다.
- 전체 레이아웃/타이포/색채 변화 이외의 기능·데이터·저장 방식은 불변이다.
- 변경 허용: 너비·여백·배경·표면·서체 크기 및 대비.
- 변경 금지: 당첨 분포, 카테고리 최대3개, 1~3칸, 전체 630개 카탈로그, 슬롯의 순차정지, 접근성 상태, 검색 팝업, 사용자의 헌정 문구.

## 비교 기준

- A: 정식 `main` — 원래 아이보리 + 더 넓은 레이아웃
- B: 실험01 — 차가운 색감 + 오브젝트 우선 (사용자 비선호)
- C: **본 실험02** — 원래 따뜻한 팔레트 + 중앙 집중 + 실험01의 슬롯/패널 비율

동일한 조건과 메뉴 개수로 비교해야 한다. 미관과 적합성을 따로 판단한다. 선호도를 다른 프로젝트에 자동 일반화하지 않는다.

## EXP-02 Patch 1 — 2026-10-17 (사용자 스크린샷 피드백)
- 슬롯 스테이지와 `메뉴 뽑기` 버튼의 하단 기준선을 데스크톱에서 맞춘다. `play-layout`의 1.3:.82 비율은 유지하며 두 열을 stretch한다.
- 상태 메시지·움직임 줄이기를 뽑기 버튼 **위**로 이동해, 주 CTA가 조작 패널의 마지막 요소가 되게 한다. 시각/키보드 탐색 순서를 일치시킨다.
- `details#guide`는 유지하고 내용 래퍼를 추가했다. `+`는 열릴 때 45도 회전해 `×`가 되고, 닫을 때 역회전한다.
- 네이티브 summary의 클릭/키보드 활성화를 Web Animations API로 보강해 열림·닫힘을 슬라이드 애니메이션 처리한다. 동작 축소 환경과 비지원 브라우저는 애니메이션 없이 native 상태만 전환한다.
- 모드, 전체 후보 균등 추첨, 1~3개, 카테고리 최대 3개, 카탈로그 검색, 저장 및 슬롯 시퀀스 변경 없음.
- 기기 너비 860px 이하에서는 기존 세로 배치 유지.
