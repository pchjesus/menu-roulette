## 목적과 디자인 판단
- 서비스 소재: 음식 이름을 골라 주는 **슬롯머신**. 주인공은 설명 카피가 아닌 조작·기대·결과를 함께 보여 주는 슬롯 오브젝트.
- 사용자 행동: 모드/방식/개수 선택 → 뽑기 → 순서별 결과 확인.
- 디자인 유형: **작업 우선 + 표현적 오브젝트** 혼합.
- 아트 디렉션: 지나친 영어 라벨과 장식선, 겹친 패널을 줄이고, 기계 본체의 광택/음영/중량감을 중심으로 완성도를 높인다.
- 색채: 기존 오렌지 머신은 브랜드 신호로 보존. 주변에는 기존 크림/갈색 관성 대신 차가운 청백색 및 잉크색 대비를 시도한다. 이것이 사용자 선호 확정 색상이라는 뜻은 아니다.
- 타이포: 실제 한글 메뉴명, 제목, 보조 글씨의 조형과 위계를 우선. 외부 폰트 의존성은 넣지 않는다.

## 비교 가능한 핵심 변경
| 영역 | 현재 main | 실험 브랜치 |
|---|---|---|
| 표정 | 크림 배경·도트 패턴·오렌지 본체 | 차가운 중립 배경·제품용 스테이지·음영을 가진 오렌지 본체 |
| 첫 시선 | 영문 eyebrow + 감성 문구 + 슬롯 | 불필요한 eyebrow 숨김, 짧은 제목과 슬롯에 집중 |
| 레이아웃 | 슬롯·설정 각각 테두리 있는 카드 | 슬롯의 오브젝트성을 강조, 설정은 가벼운 열린 레이아웃 |
| 정보 밀도 | 여러 8~11px 메타데이터 | 읽는 데 필요한 레이블·상태 글씨 상향 |
| 결과 | 검은 테두리의 말풍선 | 얇은 경계·부드러운 표면을 가진 결과 카드 |
| 카탈로그 | 따뜻한 크림 톤 | 주 화면과 일관된 중립색과 더 읽기 쉬운 작은 글씨 |

## 변경하지 않는 계약
- `getPool`, `draw`, 전체 후보 직접 균등 비복원 추첨·표시 난수 독립.
- 점메추/저메추/카페, 두 추천 방식, 카테고리 최대 3개, 추천 1~3개, 630개 메뉴.
- 순차 정지/동작 축소/슬롯 하나당 결과 하나/카탈로그 검색·초점 복귀.
- 설정 저장 및 오류 복구, `main`/GitHub Pages 정식 사이트.

## 구현 방식 및 되돌리기
- `assets/css/design-experiment.css`를 원본 `styles.css` **뒤**에서만 불러온다.
- 기존 CSS와 JS는 덮어쓰지 않는다. `index.html`에 스타일시트 1개만 추가한다.
- 되돌리려면 실험 스타일시트 `<link>`를 제거한다.
- `main` 병합 금지. 사용자 평가를 받은 뒤 필요한 개선만 발췌 적용한다.

## 비교 평가 질문
1. 슬롯이 실제 주인공으로 보이는가? 기존 버전이 더 재미있지는 않은가?
2. 찬 배경과 오렌지 기계의 조화가 매력적인가, 지나치게 차가워졌는가?
3. 제목·설정·결과의 서체와 크기가 오히려 심심해지지 않았는가?
4. 모바일에서 첫 화면의 설정 접근성과 뽑기 버튼 발견이 쉬운가?
5. 기존 기능(특히 3칸·메뉴 팝업·정지 후 결과·동작 축소)에 회귀가 없는가?
