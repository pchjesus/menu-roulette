- 실행: https://pchjesus.github.io/menu-roulette/
- 저장소: https://github.com/pchjesus/menu-roulette

- 완전 랜덤 또는 최대 3개 카테고리의 합집합에서 메뉴별 균등 추첨.

- 키보드, 결과 알림, 시스템/사용자 동작 축소 지원.

## 실행과 테스트

```sh
python3 -m http.server 8000
# http://localhost:8000
node --test
```

ES Modules를 사용하므로 file://로 직접 열지 말고 HTTP 서버를 사용하세요.
GitHub Pages는 main 브랜치의 /(root)에서 배포합니다. 상대 경로만 사용합니다.

## 추첨 원리

선택 조건에 맞는 전체 후보 배열에서 추천 개수만큼 직접 균등 비복원 추출합니다. 먼저 당첨 메뉴 전체를 결정하고, 그 후 슬롯 연출용 표시 목록을 별도 난수원으로 만듭니다. 표시 목록은 추첨 입력이 아니며, 어떤 메뉴가 표시되든 당첨 결과에 영향을 주지 않습니다. 같은 회차에는 중복이 없고 다음 실행에서는 다시 나올 수 있습니다.

## 범위와 다음 단계

v0.2: 후보 저장·저장 후보 재선택·선택적 최근 중복 방지.
v0.3: 가격·맵기·카페 필터. v1.0: 기기별 사용성·접근성 안정화.
위치·영업시간·알레르기·영양 정보를 판단하는 앱이 아닙니다. 메뉴 분류와 식사 적합성은 편집 기준이며 필요시 data 파일에서 조정합니다. 이미지와 폰트는 외부 서버에서 가져오지 않으며 슬롯머신은 CSS로 직접 제작했습니다. 참고 이미지 원본은 저장소에 포함하지 않습니다.

## v0.1.1 메뉴 확장과 슬롯 동작

[카탈로그 편집 원칙과 조사 출처](docs/MENU_CATALOG.md)를 참고하세요. 특정 토핑·브랜드·온도·크기로 후보 수를 늘리지 않고 대표명으로 정리합니다. 닭발/무뼈닭발은 별도 항목입니다.

일반 모션에서는 전 슬롯이 함께 시작하고 2.4/3.0/3.6초에 왼쪽부터 멈춥니다. 각 슬롯이 멈출 때 바로 그 순서의 큰 말풍선이 표시됩니다. 동작 축소에서는 회전 없이 같은 순서로 결과를 보여줍니다. 추첨은 전체 후보에서 직접 메뉴별 균등·회차 내 비복원 추첨합니다.

## v0.1.3 슬롯 중복 표시 수정

정지한 슬롯에는 당첨 메뉴 하나만 남습니다. 회전용 줄은 정지 시 제거하고 한 메뉴를 칸 전체 높이의 중앙에 표시해 위아래의 다른 메뉴나 중복 이름이 보이지 않도록 했습니다. 슬롯 아래 큰 말풍선은 유지합니다.

## v0.1.4 메뉴 목록 팝업

설정 패널의 **메뉴 목록 보기**를 누르면 현재 추천 모드에 해당하는 목록이 열립니다. 팝업의 **전체**를 누르면 음식/카페 630개 전체를 볼 수 있고, 점메추/저메추/카페 범위를 별도로 선택할 수 있습니다. **전체 목록/카테고리별/가나다순** 보기, 카테고리 선택, 메뉴명·카테고리 검색과 검색 지우기를 지원합니다. 목록 안의 필터는 추첨 설정을 바꾸지 않습니다. 닫기/ESC/바깥 클릭으로 닫으면 원래 버튼에 포커스가 돌아옵니다.

목록 UI는 `assets/js/ui/catalog.js`, 검색·분류·정렬 순수 로직은 `assets/js/logic/browse.js`에 분리했습니다.
